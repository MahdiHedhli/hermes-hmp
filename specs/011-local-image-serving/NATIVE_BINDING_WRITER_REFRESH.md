## Owned actor foundation (historical pre-integration checkpoint)

`local_media_native_writer_sample.py` is inert on import. `OwnedWriter` retains
its actual Thread in the caller's owner list BEFORE start effects. An explicit
ready Event proves startup; a separate gate admits at most one job. Acquisition
happens on that worker after admission. Job callbacks must verify actual public
native commit/facts themselves; a bare returned callback is not independently
inferred transaction authority. Release requires an EXACT `True` success witness and is attempted once. A false,
None or other normal return is not acknowledgment; exceptions and ambiguous
returns retain the handle/debt and are never automatically replayed. The native
integration adapter must validate the actual registry release and tracked-borrow
update before returning that witness; an unvalidated return-None callback is not
acceptable. Acquisition/release attempts, known outcomes, commit,
physical join and safe-to-close state are distinct.

Abort seals future admission and wakes an unused gate without acquiring a DB.
Once admitted, running native work is never cancelled, closed or released early:
settlement joins the SAME actual thread to completion. An attempted start with
no observed actor stays uncertain, not 'never started'; actual post-start
failures still join their retained actor. Unknown acquisition or release debt
cannot satisfy safe closure even if a thread exited. No sleep, observation
expiry or numeric-ID signal proves scheduling/settlement. The parent retains
its original actor under the unchanged 12-second observation refusal policy.

`ReadHooks` wraps genuine native methods on the private DB instance. Only the
captured reader thread emits bounded before/after method/count events (10,000
maximum); writer verification reads bypass scheduling callbacks. Events never
contain arguments, returned rows, IDs, paths or content. Original instance
attributes are retained before each replacement, including partial failures,
and restored EXACTLY only after all supplied actors are safe to close. Class
methods/native source are not modified.

Caller integration MUST add these actors to the workload DB/fixture closure
barrier, retain partial setup, and settle/verify them before hook restoration or
home/selection restoration. At this historical foundation checkpoint, integration
was not yet implemented and no native actor/data operation had run. The integrated pilot
result below supersedes this status, without closing the full matrix. The
