# Complete startup cache-absence metadata policy

November 9, 2026. This is the next complete local HMP implementation boundary.
Fresh cache probe adoption is distinct. No upstream capability blocker is proven.
The canonical startup resource and closed common-origin dispatch are preparation
only: the default startup origin is None, no factory sets it, and startup still
uses its existing traversal. No native authority, media access or deployment is
introduced by declaring these types.

The complete implementation must preserve both original passes around file and
link observations. Each path belongs to the original CacheContext paths tuple;
its source, owner, scope, registration, phase, index, actual prior pass, original
count and effect/pass publication cells must stay joined. A newer compatible
Hermes version is not a reason to disable a feature; API/security gates remain.

## Fixed policy and ordering

1. Retain the original owner/source/path component blueprints and code/type/
   constructor/member provenance before constructing the outer startup scope.
   Seal the actual Scope return and original startup-origin slot before native
   registration. A copied origin or current module export cannot nominate code.
2. Keep a separate canonical startup resource and fixed StartupArtifactOwner
   cohort. Share the existing claim, actor admission, stat/fstat producer,
   diagnostic representation, consumption, partial ACK and caller-held retirement
   machinery. Never extend DirectoryConsumer ownership or copy a dispatcher.
3. Preserve root open then root fstat. For each original component, no-follow
   stat, safe directory policy, original open and matching fstat precede descent.
   A present unapproved leaf is a refusal, never sampled absence or fallback.
4. Preserve first missing report, first ordered ancestor fstat/stat pass, exact
   missing confirmation, then a second ordered ancestor pass. Keep possible-site
   ordinals separate from actual execution count. Carry literal actual prior
   returns; matching current slots never recover a lost return.
5. Retain actual original open/FD pairs before validation, reserve every close,
   and close once in reverse order even after failure. Native status is immutable:
   use the canonical original-allocation refusal marker. Unknown closes are never
   retried or counted as closed. Source31ce4be repairs this specific cleanup path;
   corrupted-allocation/marker failures remain separate acceptance cases.
6. Return one typed raw-free finish with actual history/predecessor, outcome,
   descriptors and initial/final exact ledger/count proof. Retain that return
   across Missing/effect allocation and final callbacks. Lost returns refuse;
   there is no syscall replay or current-history receipt reconstruction.
7. Publish effect/pass result fields only into the original cells/dictionaries
   after the complete pure post-callback seal. Preserve foreign replacements.
   Carry literal native finishes in the actual before/after pass returns and
   validate them as historical receipts without granting new admission.
8. Retain no exception, traceback, raw stat object or payload. Both passes read
   zero probe bytes and inherit the existing shared quota/close reserves. Source
   counts may already include file bytes; prove the probe does not advance them.

## Required acceptance

Real missing-parent and missing-leaf full startup controls must succeed, with
both passes and actual entry/cache facts. Present/new cache, replaced ancestor,
symlink, unsupported API, permissions and structural errors must refuse without
being relabelled as absence. Test exact exception class/errno/name/subclass and
constructor failure, actor/lifetime changes at the actual C boundaries, wrong
owner/scope/registration/phase/path and zero foreign hooks. Test every partial
ACK/publication boundary, native return loss, raw retirement with cyclic GC off,
foreign slot preservation, late callback changes, quota exhaustion and original
reserved close cleanup/accounting. No read, import, execution or new entitlement
may follow merely from a missing report.

Run the meaningful existing startup and fresh-probe regressions on current and
minimum Python after integration. Static type/gate preparation is not those
passes. Entire native operations/factory/service/resource limits, authenticated
character/media delivery, physical devices and release acceptance remain open.
