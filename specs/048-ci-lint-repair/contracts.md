# Repair contract

No HMP wire, UI, Store, privilege, native client, registration or dependency
contract changes. First-stage scope is exactly the74 before/after byte pairs in
the reviewed private formatter manifest, all AST-identical excluding locations.
Keep embedded scripts byte-for-byte as AST string values. Source location and
trace events remain observable changes requiring tests; they are not waved away.

Do not substitute syntax equivalence for runtime/heap/startup acceptance or reuse
old source qualification by ancestry. Later530-diagnostic work keeps original
security/lifetime semantics or requires a separately reviewed concrete defect fix.
No feature is disabled or removed as a lint repair.

CPython3.14 additionally emits executable class `__firstlineno__` metadata; its
value changes with layout. AST equality is not equality of that generated value
or all compiled constants. The3.14 preview records these differences rather
than treating the source as byte-identical.
